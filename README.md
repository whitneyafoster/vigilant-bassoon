# Find Your Aesthetic — Lesson 1

Open `index.html` in your browser, then click **Find my look**.

## What you are learning

- **Variables**: names that hold pieces of information or parts of the page.
- **An array**: the `looks` list, which holds several aesthetics.
- **A function**: `showRandomLook`, a reusable set of instructions.
- **An event listener**: it waits for a button click, then runs the function.
- **The DOM**: JavaScript's way of finding and updating HTML.

## Your first tiny challenge

In `script.js`, add one more aesthetic object to the `looks` array. Give it a `name`, `description`, `outfit`, and four hex color codes. Refresh the browser and click the button until it appears.

## GitHub checkpoint

Once you have changed the file, make a commit whose message says what changed, for example:

`Add dark academia aesthetic option`

Avoid vague messages such as `updates` or `stuff`.
